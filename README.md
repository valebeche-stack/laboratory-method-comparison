# Laboratory Method Comparison

Educational examples of method-comparison analyses in laboratory medicine.

This repository is intended to demonstrate a reproducible, clinically oriented workflow for comparing two quantitative laboratory methods. The examples are designed for educational use and illustrate how agreement should be assessed beyond simple correlation.

## Topics covered

- paired-method data preparation
- scatter plots and identity line
- Bland–Altman analysis
- absolute and percentage bias
- Deming regression
- interpretation of analytical agreement
- distinction between correlation and agreement

## Clinical laboratory perspective

Method-comparison studies should not rely on correlation alone. Two methods can be highly correlated while showing clinically relevant systematic or proportional bias. Interpretation should therefore combine graphical assessment, regression-based comparison, bias estimates, confidence intervals, and predefined clinical or analytical acceptability criteria.

## Repository structure

- `method_comparison_demo.py` — simple Python workflow using synthetic paired laboratory data
- `example_data.csv` — synthetic example dataset
- `requirements.txt` — Python dependencies

## Important note

The dataset included here is synthetic and contains no patient information. This repository is for educational and portfolio purposes only and is not intended to replace CLSI guidance, local validation procedures, or laboratory-specific acceptance criteria.
